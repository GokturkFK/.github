# Güvenlik Politikası / Security Policy

## Zafiyet Bildirimi (Türkçe)

**GokturkFK** olarak geliştirdiğimiz tüm açık kaynak ve kurumsal yazılımlarda güvenliği birinci öncelik olarak ele alıyoruz. Herhangi bir GokturkFK reposunda güvenlik açığı tespit ederseniz, lütfen bunu herkese açık bir GitHub Issue olarak **paylaşmayın**.

### Nasıl Bildirilir?
1. İlgili reponun **Security → Advisories → Report a vulnerability** (GitHub Private Vulnerability Reporting) bölümünü kullanın.
2. Alternatif olarak kuruluş yöneticilerine doğrudan GitHub profilleri üzerinden ulaşabilirsiniz: [@uzunkubra50](https://github.com/uzunkubra50) · [@fetihcakmak](https://github.com/fetihcakmak).

### Neleri Eklemelisiniz?
- Etkilenen repo ve sürüm/commit bilgisi
- Zafiyeti yeniden üretme adımları (PoC)
- Olası etki değerlendirmesi ve varsa çözüm önerisi

Bildiriminizi aldıktan sonra en geç **72 saat** içinde geri dönüş yapmayı ve doğrulanan bulgular için hızlı bir yama takvimi paylaşmayı hedefliyoruz.

## Reporting a Vulnerability (English)

At **GokturkFK**, security is a first-class engineering priority across both our open-source security platforms and enterprise systems. If you discover a security vulnerability in any GokturkFK repository, **please do not open a public GitHub issue**.

### How to Report
1. Use **GitHub Private Vulnerability Reporting** under the repository's **Security → Advisories → Report a vulnerability** tab.
2. Alternatively, reach out directly to the organization maintainers: [@uzunkubra50](https://github.com/uzunkubra50) · [@fetihcakmak](https://github.com/fetihcakmak).

### What to Include
- Affected repository and version / commit SHA
- Clear reproduction steps or minimal proof of concept
- Potential security impact and any suggested remediation

We aim to acknowledge all reports within **72 hours** and coordinate responsible disclosure once a fix is verified.
